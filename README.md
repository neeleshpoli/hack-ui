# Hack UI
Short for Hackathon UI. Hack UI is a simple framework to help design UIs rapidly, especially in time constrained scenarios such as hackathons. 

## Packages
Hack UI provides 3 packages: 
- `@hack-ui/ui`: Provides prestyled HTML components. A simple theme is provided and can be adjusted for a custom look.
- `@hack-ui/components`: Provides ready to use components.
- `@hack-ui/pages`: Provides ready to use pages and page layouts

## Default theme
By default, Hack UI sticks to a simple black and white theme. System fonts are used by default.
